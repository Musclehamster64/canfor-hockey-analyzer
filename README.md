# NHL Fantasy Hockey Analyzer

A personal PowerShell application designed to help analyze NHL fantasy hockey players, compare player performance, and evaluate upcoming schedules.

## Features

- NHL player statistics and category analysis
- Fantasy pickup scoring
- Upcoming weekly game counts
- Off-night schedule analysis
- Player comparison tools
- Sortable player statistics and filters

## Technology

- Windows PowerShell
- WPF desktop interface
- NHL statistics data

## Intended Use

This project is intended for personal, read-only analysis of a Yahoo Fantasy Hockey league. It is not a commercial product and does not modify league rosters or transactions.
